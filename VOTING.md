# Prequisits
To fully understand this project you need basic knowledge about systemd and hackclubs nest.
### Systemd
Systemd is Linux buildin service manager, it allows you to start programs automatically when sour machine starts.
### [Nest](https://hackclub.app)
A free linux vps for highschoolers provided by hackclub. \
It also allows you to register hackclub.app subdomains through caddy.

# Function
This project allows you to create the service and subdomain for a project in a single command, furthermore it creates short commands to manage the service.

# How to try it
If you don't have nest already, you can't try it, because it takes about 24h to get verified. \
I'd still reccomend to register, because it's a great thing to have. \
If you have nest check out the installation guide in the README or release.
